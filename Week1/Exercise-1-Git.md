The commands I used:
git init: Initialized git repo
git config user.name: to check/verify the username
git status: to know the current status of the git
git add: to add to staging
git commit -m "MESSAGE": commit/save the changes of the files that are in staging area
git push: push/upload the commits
git clone: git clone https://github.com/Venny12/Exercise1.git clone-folder - created a copy into a new folder named clone-folder.
git fetch - download new commits - read only
git pull -Fetch the new commits from the remote and merge into your current branch.
git push -u origin feature/add-priority - Push the branch
git switch main - switch back to main
